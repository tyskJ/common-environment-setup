# Obsidian インストール手順

## Mac

### 1. `Obsidian` インストール

```zsh
brew install --cask obsidian
```

> [!NOTE]
>
> - `Applications` フォルダから `Obsidian` が起動できればOKです

## Windows

### 1. インストーラダウンロード

[Obsidian公式サイト](https://obsidian.md/) からインストーラをダウンロード

### 2. インストーラ実行

- インストーラを実行します。※基本デフォルトで問題ありません。
- インストール完了後、`Obsidian` が起動できればOKです
