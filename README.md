# 各種ツールのセットアップ手順

* 各プロジェクトで使用しているツールやモジュール等のセットアップ手順及びエラー解消方法をまとめています。

| ツール | 概要 |
| --- | --- |
| [AWS CDK](./awscdk) | プログラミング言語で AWS リソースを定義・デプロイする IaC フレームワーク |
| [AWS CLI](./awscli) | AWS の各サービスをコマンドラインから操作する公式 CLI |
| [CloudFormation Linter](./cfn-lint) | CloudFormation テンプレートを検証する Linter |
| [Claude](./claude) | Anthropic の AI アシスタント (Claude Code / Claude Desktop) |
| [Git](./git) | 分散型バージョン管理システム (Windows は Git Bash を標準シェルとして使用) |
| [GitHub CLI](./github_cli) | GitHub をコマンドラインから操作する公式 CLI |
| [GnuPG](./gnupg) | 暗号化・電子署名ツール (Git コミットの署名に使用) |
| [jq](./jq) | JSON をコマンドラインで整形・抽出・加工するツール |
| [make](./make) | Makefile に定義したタスクを実行するビルド自動化ツール |
| [mise](./mise-en-place) | 開発ツールのバージョンや環境変数をまとめて管理するツール |
| [Node Package Manager](./node_package_manager) | Node.js のパッケージ管理ツール (pnpm) |
| [Node Version Manager](./node_version_manager) | Node.js のバージョン管理ツール (nvm / nvm-windows) |
| [Obsidian](./obsidian) | Markdown ベースのナレッジベース / メモアプリ |
| [OCI CLI](./ocicli) | Oracle Cloud Infrastructure をコマンドラインから操作する公式 CLI |
| [Python Install Manager (PIM)](./pim) | Windows 向けの公式 Python インストーラー兼バージョン管理ツール |
| [Postman](./postman) | API の動作確認やテストを GUI で行う API クライアント |
| [pyenv / Python3](./pyenv_python3) | Python のバージョン管理ツール (Windows は pyenv-win) |
| [rain](./rain) | AWS 製の CloudFormation 用 CLI |
| [SSM Plugin](./ssmplugin) | AWS CLI から Session Manager を利用するためのプラグイン |
| [tenv / Terraform / TFTUI](./tenv_terraform_tftui) | Terraform のバージョン管理ツール / IaC ツール / TUI ツール |
| [uv / Python3](./uv_python3) | Rust 製の高速な Python パッケージ / プロジェクト管理ツール |
